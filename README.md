A short original poem about agency — the power to choose and to act — in the moment two agents agree on one plan. Each holds a key; neither can open the door alone. The poem is written by `main.py` (Python 3.13, standard library only, no network) to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
